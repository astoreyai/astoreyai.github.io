# Contributing

Report website issues in [this repository](https://github.com/astoreyai/astoreyai.github.io/issues).
For career facts or publication changes, confirm the current CV and evidence
before changing public copy. Do not infer acceptance, publication, funding,
or deployment status from a project name or a draft.

Use the build and verification commands in [README.md](README.md). Include
screenshots of changed pages and describe the checks performed. Keep changes
focused on the portfolio; private career records do not belong in this repository.
